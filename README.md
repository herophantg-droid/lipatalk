# lipatalk

Голосовые и видеокомнаты в браузере. Среда передаётся через SSE по HTTPS — STUN/TURN/UDP не нужны.

## Запуск локально

```bash
node server.js
# http://localhost:5173
```

## E2EE

Ключ AES-GCM (256 бит) генерируется в браузере и попадает только во фрагмент ссылки `#k=...`.
Сервер получает только шифртекст аудио, видео и чата. Метаданные (кто в комнате, когда зашёл) видны серверу.

- Создатель комнаты получает ссылку с ключом — копируйте её и отправляйте друзьям.
- При входе по коду без ключа вставьте ключ из приглашения в поле «Ключ шифрования».

## Деплой

Обычное Node-приложение: `npm start` → `node server.js`, порт из `PORT`.
